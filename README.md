# Análise de Churn — Módulo 15

Projeto acadêmico do curso **Profissão Cientista de Dados**, com análise exploratória de dados de clientes de telecomunicações para investigar o **churn** (cancelamento de serviços).

## 🛠️ Tecnologias
- Python
- Pandas e NumPy
- Matplotlib, Seaborn e Plotly
- Jupyter Notebook

## 🔎 Etapas
- Análise descritiva e distribuição das variáveis.
- Investigação de possíveis outliers.
- Análise da relação entre churn e características dos clientes.

## ▶️ Como executar
1. Instale as bibliotecas: `pip install pandas numpy matplotlib seaborn plotly jupyter`
2. Disponibilize o arquivo `CHURN_TELECON_MOD08_TAREFA_PART_02.csv` no diretório do notebook.
3. Abra o notebook no Jupyter e execute as células.

## 📌 Observação
A análise busca identificar características associadas ao cancelamento e apoiar futuras estratégias de retenção. Associação entre variáveis não implica causalidade.
